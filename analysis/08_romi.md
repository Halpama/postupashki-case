# 08. ROMI

Для внешнего платного размещения:

`ROMI = (Attributed Revenue - Cost) / Cost * 100%`

В production-расчёте `Attributed Revenue` берётся из фактического `net_revenue` заказов, распределённого движком `last_non_direct` в окне 7 дней. Для внутреннего канала используется окно 30 дней; стоимость собственных публикаций должна быть выделена отдельно, иначе ROMI собственного канала нельзя интерпретировать как платную окупаемость.

Исторический ROMI по предоставленной выгрузке не рассчитывается: источники продаж неизвестны, а реальные расходы на рекламу отсутствуют. Для бюджета 300 000 ₽ сначала нужны реестр размещений, трекинг-ссылки, подтверждение оплаты и сверка выручки с платежным шлюзом.
